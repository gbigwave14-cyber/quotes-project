# Quotes Project — «Случайная цитата»

Одностраничное веб-приложение на чистом HTML/CSS/JavaScript, которое показывает случайные цитаты из отдельного JSON-файла. Без сборки, без зависимостей, без бэкенда: достаточно открыть страницу в браузере.

- Репозиторий: <https://github.com/gbigwave14-cyber/quotes-project>
- Страница приложения: [`quote.html`](quote.html)
- Данные: [`quotes-ru.json`](quotes-ru.json)

## Возможности

- Фильтр по категориям: из файла берутся только цитаты категорий **Мудрость**, **Мотивация** и **Работа** (настраивается константой `CATEGORIES`).
- Кэширование набора цитат на текущий день: пока кэш свежий, страница не обращается к сети вообще — один запрос к источнику в сутки.
- Случайный порядок цитат: каждая «колода» показывает все отобранные цитаты по одному разу, после чего перемешивается заново (без повтора текущей цитаты подряд).
- Навигация вперёд/назад по истории просмотра и счётчик вида `3 / 7`.
- Кнопка копирования цитаты в буфер обмена (с форматированием «текст» + автор + категория).
- Категория цитаты выводится отдельным бейджем.
- Индикатор состояния: количество загруженных цитат, признак «из кэша», ошибка загрузки и кнопка «Повторить».
- Светлая и тёмная тема — автоматически по системной настройке (`prefers-color-scheme`).
- Уважение к `prefers-reduced-motion`: анимации отключаются.
- Адаптивная вёрстка (мобильные экраны), доступность: `aria-live`, `aria-label`, видимый focus-ring, семантический `<blockquote>`; мелкий текст соответствует WCAG AA по контрасту.
- Устойчивость: таймаут запроса 10 секунд (`AbortController`), fallback-копирование через `document.execCommand('copy')` для браузеров без `navigator.clipboard`, `<noscript>`-предупреждение.

## Быстрый старт

Просто откройте `quote.html` в браузере — файл работает и по протоколу `file://`, потому что `raw.githubusercontent.com` отдаёт `Access-Control-Allow-Origin: *`.

Альтернатива — локальный статический сервер:

```bash
python -m http.server 8000
# затем http://localhost:8000/quote.html
```

Сеть нужна только для первой загрузки в сутки: дальше набор берётся из локального кэша (см. раздел «Кэш на день»).

## Горячие клавиши

| Клавиша | Действие |
| --- | --- |
| `→` | Следующая цитата |
| `←` | Предыдущая цитата |
| `Пробел` / `Enter` | Следующая цитата |
| `C` (в т.ч. в русской раскладке) | Скопировать текущую цитату |

Горячие клавиши не перехватываются, когда фокус находится на кнопке (`Пробел`/`Enter` остаются за кнопкой), и когда нажата любая из клавиш-модификаторов (`Ctrl`, `Alt`, `Cmd`). Удержание клавиши не листает цитаты: автоповтор (`event.repeat`) игнорируется.

## Источник данных

Приложение запрашивает JSON по адресу, заданному константой `SOURCE_URL` в начале `<script>` страницы `quote.html`:

```js
const SOURCE_URL = 'https://raw.githubusercontent.com/gbigwave14-cyber/quotes-project/main/quotes-ru.json';
```

Чтобы использовать свой список цитат, замените эту константу на путь к своему файлу. Запрос идёт с `cache: 'no-cache'`, поэтому браузер сверяет файл с сервером по ETag и получает `304 Not Modified`, если он не изменился.

Требования к данным:

- корень — массив объектов;
- обязательное поле `text` (непустая строка);
- необязательные поля: `author` (по умолчанию «Неизвестный автор»), `category`, `id`;
- `category` должен совпадать с одной из категорий из `CATEGORIES` (без учёта регистра) — иначе запись отбрасывается;
- записи без корректного `text` молча отбрасываются; если валидных записей не осталось — показывается ошибка с перечнем ожидаемых категорий.

Пример:

```json
[
  {
    "id": 1,
    "text": "Жизнь — это то, что происходит с тобой, пока ты оживлённо строишь другие планы.",
    "author": "Джон Леннон",
    "category": "Жизнь"
  }
]
```

## Фильтр по категориям

Список допустимых категорий задаётся константой:

```js
const CATEGORIES = ['Мудрость', 'Мотивация', 'Работа'];
```

- Сравнение регистронезависимое (`Мотивация` = `мотивация`).
- Пустой массив `[]` отключает фильтр — показываются все корректные записи файла.
- Фильтр применяется на этапе нормализации данных, то есть до записи в кэш: в кэше всегда лежит уже отфильтрованный набор.

Текущий файл `quotes-ru.json` содержит 15 цитат, под фильтр попадают 7 из них: Мотивация (4), Мудрость (2), Работа (1). Категории Успех, Философия, Жизнь, Гуманизм и Саморазвитие не показываются.

## Кэш на день

Чтобы не запрашивать источник при каждом открытии страницы, полученный набор кэшируется в `localStorage` под ключом:

```js
const CACHE_KEY = 'quotes-cache-v1';
```

Формат записи:

```json
{
  "day": "2026-10-29",
  "url": "https://raw.githubusercontent.com/.../quotes-ru.json",
  "categories": ["Мудрость", "Мотивация", "Работа"],
  "quotes": [{ "text": "...", "author": "...", "category": "..." }]
}
```

Логика:

1. При запуске сначала читается кэш. Если запись валидна — набор сразу показывается, статус пишет «Цитат из кэша: N», сеть не используется.
2. Если кэша нет или он не подходит — выполняется `fetch`, набор нормализуется, фильтруется, кэшируется и показывается.
3. Запись считается устаревшей, если не совпадает хотя бы одно из полей: `day` (сегодняшняя локальная дата `ГГГГ-ММ-ДД`), `url` (адрес источника) или `categories` (текущий фильтр). Так смена источника или списка категорий автоматически инвалидирует кэш.
4. Кэш необязателен: если `localStorage` недоступен (приватный режим, запрет хранилища) или содержит битые данные, страница просто работает через сеть, как раньше.

Сбросить кэш вручную: DevTools → Application → Local Storage → удалить ключ `quotes-cache-v1` (или выполнить `localStorage.removeItem('quotes-cache-v1')` в консоли).

Ограничение: изменения в `quotes-ru.json` подхватываются на следующий день — до этого показывается сегодняшний снимок набора.

## Структура проекта

```
quote.html     # вся страница: разметка, стили и логика в одном файле
quotes-ru.json    # набор цитат (массив объектов)
README.md         # этот документ
```

Внутри `<script>` логика разделена на блоки:

- данные — `isWanted`, `normalize`, `shuffle`, `emptyMessage`;
- кэш — `todayKey`, `sameCategories`, `readCache`, `writeCache`;
- загрузка — `load`, `apply`, `describeError`;
- отображение — `draw` (единственная точка включения/выключения частей интерфейса по фазе `state.phase`) и `flash`;
- навигация — `next`, `prev`;
- копирование — `legacyCopy`, `writeClipboard`, `copyCurrent`;
- обработка горячих клавиш и инициализация.

Состояние хранится в одном объекте `state`: `quotes` (полный набор), `deck` (текущая перемешанная колода), `pos` (позиция в колоде), `phase` (`idle` / `loading` / `ready` / `error`).

## Настройка

| Константа | Значение по умолчанию | Назначение |
| --- | --- | --- |
| `SOURCE_URL` | URL `quotes-ru.json` на GitHub | Адрес источника цитат |
| `CATEGORIES` | `['Мудрость', 'Мотивация', 'Работа']` | Какие категории показывать (`[]` — все) |
| `CACHE_KEY` | `quotes-cache-v1` | Ключ кэша в `localStorage`; меняйте вместе с форматом данных |
| `REQUEST_TIMEOUT_MS` | `10000` | Таймаут загрузки данных |
| `FEEDBACK_MS` | `1500` | Длительность сообщений «Скопировано» / «Загружено» |

## Известные ограничения

- Первый запуск за сутки требует доступа в интернет (если кэш пуст или устарел). Если сеть недоступна, показывается ошибка и кнопка «Повторить».
- Кэш живёт в рамках календарного дня по локальному времени устройства: смена даты или часового пояса приводит к новой загрузке.
- Изменения в источнике появляются на странице на следующий день.
- Копирование зависит от разрешений браузера; при запрете используется устаревший `execCommand`-fallback, а если и он недоступен — выводится сообщение об ошибке.
- Нет автоматических тестов, линтера и сборки — проект намеренно состоит из двух файлов.
